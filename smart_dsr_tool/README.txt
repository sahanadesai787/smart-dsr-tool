SMART DSR TOOL - DAILY USE

WHAT IT DOES
- Upload a daily Sales Order Report and master Excel/CSV files.
- Maps EAN, style, size, categories, vendor cost, channel and week where matching master columns exist.
- Calculates TTL Vendor Cost, TTL ESP, TTL MRP and TTL RGM.
- Exports an Excel workbook with DSR, Mapping Issues (if any), and Formula Guide sheets.

FIRST-TIME SETUP (Windows)
1. Install Python 3.11+ from https://www.python.org/downloads/
2. During installation, tick "Add Python to PATH".
3. Extract this ZIP to a folder you can find again.
4. Double-click Run_Smart_DSR.bat.
5. A browser tab will open. If it does not, copy the local URL shown in the black terminal window into Chrome.

DAILY USE
1. Double-click Run_Smart_DSR.bat.
2. Upload the latest Sales Order Report.
3. Upload Globus Cataloging, Item Master, Channel Master, Vendor Cost and Week Master.
4. Upload Myntra report only if needed; upload DSR Template if you want to refer to it.
5. Click Generate DSR Excel.
6. Review preview and Mapping Issues, then click Download DSR Excel.

IMPORTANT
- The app processes uploaded files locally on your computer; it does not automatically send them to a website.
- Lookup mappings are generated by matching the available column names. If your source file columns change, inspect the output and Mapping Issues sheet.
- The current default TTL QTY is 1 per sales-order row when the source has no quantity column.
- TTL ESP defaults to Selling Price x TTL QTY. Confirm your channel-specific ESP / currency conversion business rules before submitting an official report.
- TTL Vendor Cost = Vendor Cost x TTL QTY; TTL MRP = MRP x TTL QTY; TTL RGM = TTL ESP - TTL Vendor Cost.
- The uploaded DSR template is optional and currently not copied as the final workbook layout; the app outputs the requested standard DSR columns.
